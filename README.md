# Погодный информер на Python (OpenWeatherMap API)

Простая программа на Python, которая показывает текущую погоду в выбранном городе с использованием **OpenWeatherMap API**. 
Программа запоминает последний введенный город в текстовый файл, позволяя обновлять данные или менять город без перезапуска.

## Особенности
* **Автосохранение**: Название города сохраняется в файл `citys.txt`.
* **Интерактивность**: Смена города или обновление погоды происходят внутри активной сессии (через цикл).
* **Многоязычность**: Описание погоды выводится на русском языке.
* **Защита от ошибок**: Автоматическая обработка опечаток в названиях городов и обработка сбоев сети.

## Как запустить проект

### 1. Клонирование репозитория (или скачивание)
Перейдите в терминале в нужную папку и выполните:
```bash
git clone https://github.com
cd sky_info
```

### 2. Установка зависимостей
Для работы скрипта требуется библиотека `requests`. Установите её через pip:
```bash
pip install requests
```

### 3. Настройка API Ключа
В коде уже прописан рабочий ключ, но если вы хотите использовать свой:
1. Зарегистрируйтесь на сайте [OpenWeatherMap](https://openweathermap.org).
2. Перейдите в раздел **API keys** и создайте бесплатный ключ.
3. Откройте файл `info.py` и замените значение в переменной `API_KEY`:
   ```python
   API_KEY = "ВАШ_ЛИЧНЫЙ_API_KEY"
   ```

### 4. Запуск программы
Запустите скрипт через терминал или вашу среду разработки (IDE):
```bash
python main.py
```

## Использование

1. При первом запуске программа попросит ввести название города (например, `Москва` или `Лондон`).
2. Откроется окно с текущей температуру, то, как она ощущается, и текстовое описание погоды.
3. Используя настройки имеется возможность для:
   * Смена темы
   * Смена города
   * Сменя языка
   * Возвращение в главное меню
## Технологии
* **Python 3.10**
* **Библиотека `requests`** — для отправки HTTP-запросов.
* **GUI** - PyQt6
* **OpenWeatherMap API** — в качестве источника погодных данных.
* **Встроенные модули `os`** — для работы с файловой системой.
